# Project Constraints

Implement only a safe shop-level monitor and daily topic summary.

Allowed saved data:

- thread_url
- last_seen_res_no
- last_seen_hash
- last_checked_at
- new_count_today
- summary_date
- latest_res_no
- topic counts
- manual check ranges
- technical error timestamps/counts

Disallowed:

- saving post text
- saving raw HTML
- translating post text
- extracting or indexing individual names, stage names, nicknames, appearance, service details, or personal reviews
- collecting nn/ns or other service-detail categories
- bulk crawling, concurrent crawling, login bypass, captcha bypass, proxy pools, or anti-bot bypass
